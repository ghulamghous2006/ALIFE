# ALIFE

A personal AI assistant that runs locally on Windows. ALIFE uses Ollama (`qwen3:4b`) for conversation, SQLite for memory, a controlled tool registry for computer actions, and optional offline voice input/output.

Current version: **v0.4 — Voice + Controlled Tools**

ALIFE is not autonomous. It only runs explicitly registered tools and never executes arbitrary shell commands generated by the model.

---

## Features

- Typed terminal chat with the ALIFE system prompt
- Persistent conversation history and long-term memories in SQLite
- Offline voice via `/voice` (Faster-Whisper + pyttsx3)
- Controlled tools: time, system info, approved websites, approved applications
- Shutdown requests are **dry-run only** and cannot power off the computer
- Optional Windows logon auto-start

---

## Requirements

- Windows
- Python 3.12+ (developed with 3.13)
- [Ollama](https://ollama.com/download) installed and running
- Local model: `qwen3:4b`
- Microphone and speakers for `/voice`
- A Windows desktop/logon session for auto-start

copy .env.example .env

```powershell

```

Voice extra notes:

- `faster-whisper` downloads the `tiny` model on first use and caches it.
- Windows microphone permission must be allowed for the terminal app.
- If `pyttsx3` fails, ALIFE still shows the typed/spoken transcript response.

## Commands

| Input | Effect |
|---|---|
| normal text | Conversational reply, or a registered tool if the request matches |
| `/voice` | Record ~6 seconds, transcribe, run the same pipeline as typed chat, speak the reply |
| `/remember <text>` | Save a long-term memory |
| `/recall` or `/memories` | List stored memories |
| `/forget <id>` | Delete one memory |
| `/clear-memory` | Delete all memories |
| `/history` | Show recent conversation history |
| `/clear-history` | Clear conversation history |
| `exit` or `/exit` | Quit |

## Tools

Natural language is enough. Examples:

- `What time is it?`
- `Open YouTube`
- `Please open GitHub`
- `Launch Chrome`
- `Open VS Code`
- `What time is it, then open YouTube`

Approved websites: YouTube, LeetCode, Google, GitHub.

Approved applications (Windows paths in `tools/config.py`): Chrome, VS Code, WhatsApp.

Unknown websites/apps return a configuration error instead of inventing a command.

### Shutdown safety

`Shut down my laptop` asks for confirmation (`yes` / `no` only). Even after `yes`, ALIFE **does not** run `shutdown.exe` or any other power-off command. Real shutdown execution is disabled.

## Automatic Windows startup

Enable:

```powershell
powershell -ExecutionPolicy Bypass -File C:\Users\ghula\OneDrive\Desktop\ALIFE\scripts\enable_startup.ps1
```

This registers a current-user Task Scheduler task named `ALIFE Auto Start` that opens a **visible** PowerShell window at logon.

Disable:

```powershell
powershell -ExecutionPolicy Bypass -File C:\Users\ghula\OneDrive\Desktop\ALIFE\scripts\disable_startup.ps1
```

Verify without restarting Windows:

```powershell
Get-ScheduledTask -TaskName "ALIFE Auto Start"
powershell -ExecutionPolicy Bypass -File C:\Users\ghula\OneDrive\Desktop\ALIFE\scripts\verify_startup.ps1
```

Startup errors are appended to `data\startup.log`. Duplicate instances are blocked by `data\alife.lock`.

## Troubleshooting

**Ollama is not ready**
Start Ollama first. ALIFE retries briefly, then exits with a clear error if the server never responds.

**Voice heard nothing**
Speak during the 6-second listening window. Check Windows microphone privacy settings. Empty transcription is ignored and is not sent to tools.

**YouTube opened from typing but not from a combined voice request**
Combined requests such as `What time is it, then open YouTube` now execute each supported action in order. Use `/voice` and speak both parts clearly.

**Application not configured**
Edit `tools/config.py` `APPLICATION_REGISTRY` with an explicit executable path. `%USERNAME%` is expanded. Missing files are reported instead of fake success.

**ALIFE is already running**
Only one instance is allowed. Close the existing window or delete a stale `data\alife.lock` if the previous process crashed.
